## What's new
- Filter the list in Settings → Search sources by category, such as Movies, Anime or Books.
- The Browser tab icon now has its own little animation, like the other tabs.

## What's changed
- About is now the first row under App in Settings.
- Settings shows its scrollbar, a stronger fade at the bottom, and a More below hint that stays until you've scrolled to the end once.
- Closing a sheet, such as Sort and filter or the add menu, puts TalkBack back on the button that opened it.
- TalkBack says what happened: "Searching 28 sources", the number of results when a search ends, "Added", "Removed" for a recent search, and where a tab moved after you reorder it.
- The search progress is no longer read out on every count change.
- Categories, sort and source choices are read as one pick-one group.
- The recent searches list and the quick check line fade in instead of popping up.
- Numbers that change, such as the search count and upload age, no longer shift as they update.

## What's fixed
- In the light theme, the text on the GitHub star ticket is easier to read.
- The peer and tracker lists in a torrent's details keep TalkBack's place when they refresh.
