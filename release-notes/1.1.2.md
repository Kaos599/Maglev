## What's new
- Search has a new Best match order, now the default. Results that contain every word you typed come first, then the most shared. Change it in the sort sheet.
- Settings → Search sources has "Include adult results in All", shown while Show adult sources is on. It is off by default, so adult sources and results appear only under the Adult chip.

## What's changed
- Torrents-CSV is now off by default because it returned unrelated results. Turn it back on in Settings → Search sources.
- If your search order was "Most shared", it moves to Best match once. Pick "Most shared" again and it stays.

## What's fixed
- Adult results no longer show up in a normal search such as "dune" when Show adult sources is off, even when a source did not label them as adult. Films labelled movies or TV, such as "xXx (2002)", are never hidden.
