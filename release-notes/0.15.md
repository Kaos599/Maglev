## What's new
- Each search result shows what kind of file it is (video, music, book, app, game) with an icon, and says how long ago it was uploaded.
- Tap the search box to see your recent searches.
- When a source needs a quick check, Search shows one line with a Fix button, and Settings → Search sources lists those sources at the top with a ? to tap.
- Hold a tab and drag it to reorder your tabs in Settings → Appearance → Tabs.
- A star ticket in Settings → About opens Maglev on GitHub.

## What's changed
- Search is calmer: before you search it shows only the box and categories, and results start right under one line with the count and sort. To see results from a single source, use Sort and filter.
- While searching, one line and a thin bar show how many sources have answered.
- The Browser button on Search is smaller, and hides when the Browser has its own tab.
- The empty Transfers screen leads with Add a link, with Search and Browser underneath.
- Settings shows a hint the first time that more settings are further down.

## What's fixed
- Dark app icon previews, such as Mono, no longer blend into the background.
