## What's new
- Subtitles. Find and save subtitles for your videos, from 21 free sources, with no account. It works while a video is still downloading: Maglev matches by name, then checks for an exact fit once the file finishes. Tap the pencil to change the name it searches for. The subtitle is saved next to the video so players pick it up. If one is already there, you choose Replace or Keep both. Pick languages and sources in Settings > Finding things > Subtitles.
- Get subtitles as you add. After you add a film or an episode from Search, the Added message offers Get subtitles. Add several quickly and they share one message. Get subtitles for 3 opens a list where you tick the ones you want, and each row shows the quality and size so two releases of the same film are easy to tell apart. The Add screens have a Subtitles switch for that add.
- Get subtitles for new videos, in Settings > Subtitles. With it on, every video you add gets subtitles in your languages while Maglev is open, from Search, links, feeds or a shared magnet. A close match is never saved without you: the card shows a ? until you pick one.
- Each download's page has a Subtitles row that says what happened in words (saved, close match, none found yet) with the one button that fits: Pick one, Edit name, Change or Cancel.
- Link downloads have their own page, like torrents: progress, speed, where the file came from and where it's saved. If a link stops working, the page says why. Paste a new link to the same file and tap Update link to carry on from where it stopped.
- Choose how much a download's page shows, in Settings > Appearance > Download page. Compact shows the speed and time left. Detailed adds amounts, connections and timing. Previews show both before you pick.
- Transfers says why a download is held (Wi-Fi only, battery, schedule, storage full and more), with a button for that setting.
- Swipe a row in Transfers right to pause or resume it, or left to remove it from the list. Files are kept. Turn it off in Settings > Appearance.
- Each card in Transfers can show an icon for its file type. A torrent gets the icon of its biggest file. Turn it off in Settings > Appearance.
- Search has a size range slider, to hide results that are too small or too big.
- In the browser, swipe the address bar left or right to switch tabs, or down to see them all. Turn it off in Settings > Browser.
- Backups can include your stats. Tick Include stats when you export.
- Every setting can be found with Settings search.
- After an update, a short window shows the main new feature. Turn it off in Settings > Updates.

## What's changed
- A card no longer says Downloading when nothing is arriving. Before any data comes in it says Connecting to peers, with how many it has found. When data stops for 5 seconds it says Waiting for peers. Links say Connecting to the server and Waiting for the server.
- While data arrives, a card shows how much is done next to the speed, for example 320 MB of 2.1 GB · 2.1 MB/s.
- When a download isn't moving, its page explains why: peers found and connected, trackers that replied, how long it has tried or when data last came in, and an Ask trackers again button.
- The Added message after a one-tap add sits above the tab bar, so the results you're tapping don't jump. The add button turns into a spinner while it adds, then a ✓.
- Every card in Transfers has one status line, so all cards are the same height.
- The Downloads group in Settings is now called Transfers, like the tab. Its first page is Adding and finishing.
- The browser blocks more tricks. A download a page starts by itself goes to the Files tray with a notice. Pages can't fill your Back history to keep you on them. Known crypto-mining scripts are blocked. Pages open over HTTPS when the site supports it, and fall back to HTTP if the site doesn't answer.
- Undo after removing a row lasts as long as Android's accessibility timeout asks, and never less than 5 seconds.

## What's fixed
- In Search, a torrent you added and then removed from Transfers still showed as added. You can add it again now.
- After Shut down, or after Maglev closed itself when downloads finished, adding a torrent failed with "The download engine isn't running yet". Maglev now starts the engine again when you add, resume or change something. If it can't, it says why and offers Start engine. Shut down still stays shut down until you do something.
- Pause all and Resume all in the notification did nothing if Android had closed Maglev in the background. They now start the engine first, and both show when one transfer is running and another is paused.
- Tapping a page in the browser could open pop-ups and pop-unders. A tap now opens a new window only for the link you tapped.
- The Transfer details switch in Settings > Appearance didn't change anything. It's now Download page, and it does.
- On a torrent's page, the timing row touched the boxes above it.
- A finished link download's page showed a dash for Time left. It now says Done.
- Maglev could fail to start after Clear data when files from an earlier install were still in the download folder.
