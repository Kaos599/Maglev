## What's new
- Search for torrents from the Search tab, with categories, sorting and a live list of sources.
- Results from sources that are often unsafe carry a warning, and you confirm before adding one.
- Set a speed limit for one torrent, and move a torrent's files to another folder.
- Auto-download new items from feeds that match rules you set.
- A finished download sends an alert that opens the torrent.
- Choose which files to download in a torrent, with a priority for each.
- A magnet link shows the peers found while it loads, and you can start now or choose files.
- Free space is checked before a download starts.
- On Android 16 and later, download progress shows as a Live Update in the notification.

## What's changed
- The app icon is new, and all icons use one pixel style.
- Pause and resume respond at once, and speeds are smoothed.
- Each file in a torrent shows its own state.

## What's fixed
- Very slow speeds no longer show "undefined/s".
- A schedule's 0 (no limit) no longer overrides a real limit.
- Speed limits hold more closely, without a full second of extra burst.
- Search titles show characters such as & as normal text.
