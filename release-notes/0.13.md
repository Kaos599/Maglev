## What's new
- The + button opens one menu: paste or type a link, open a .torrent file, search, or open the browser.
- The add screen takes ordinary web links as well as torrents. You can rename a link and choose where it saves before you add it.
- Every download shows its size and progress, for example "412 MB of 1.2 GB · 34%".
- Open folder is on every download in Transfers, and finished link downloads can be opened and shared like torrents.
- On mobile data, the add screen tells you the size before you start.
- Pick a font style in Settings: Clean, Retro or Mono.
- New welcome screens, with a small train animation.

## What's changed
- Sizes read "412 MB" instead of "412.0 MB".
- The speed at the top of Transfers now includes link downloads.

## What's fixed
- After a fresh install or clearing the app's storage, Maglev could open the browser instead of the welcome screens.
- The download notification no longer disappears when only link downloads are running.
- Paste link works on the empty Transfers screen.
