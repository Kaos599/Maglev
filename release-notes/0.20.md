## What's new
- Search results show the full torrent name over two lines, so you can read the resolution, codec and release group before you add one. Pick 1, 2 or 3 lines, or the full name, in Settings → Search sources → Result name lines.
- In the browser, each file Maglev finds shows its size. Streams show an estimate marked with "~", and "—" means the site doesn't say.
- The browser's file list opens on Video when the page has one, names the page each file came from, and hides tiny files (tap "hidden" to see them).
- Remove a file or clear the list, with Undo. "Scan again" brings back everything on the page.
- Long-press a file to pick several and download them together.
- Files you already have show "In Transfers", and the browser shows how many are downloading.
- Save one download to a subfolder without changing where the others go.

## What's changed
- The total speed bar and Pause all button above your transfers are hidden by default. Turn them back on in Settings → Appearance → Speed totals. Pause all is still in the notification.
- The browser's file list now shows only the files on the page you're looking at. It used to keep files from every page you opened.
- Maglev no longer asks Android for the "draw over other apps" or fingerprint permissions. It never used them.
