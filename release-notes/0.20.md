## What's new
- Search results show the full torrent name over two lines, so you can read the resolution, codec and release group before you add one. Pick 1, 2 or 3 lines, or the full name, in Settings → Search sources → Result name lines.
- In the browser, each file Maglev finds shows its size. Streams show an estimate marked with "~", and "—" means the site doesn't say.
- Clear the browser's file list with one tap, or remove one file with its ×.

## What's changed
- The browser's file list now shows only the files on the page you're looking at. It used to keep files from every page you opened.
- Maglev no longer asks Android for the "draw over other apps" or fingerprint permissions. It never used them.
