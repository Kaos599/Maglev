## What's new
- Bookmarks in the browser. Choose Add bookmark from the page menu, and a bookmark icon in the address bar shows the page is saved. Bookmarks are on a new tab's start page, at the top of address-bar suggestions, and in Bookmarks (page menu or Settings → Browser), where you can search, rename, remove and move one to the top. Backups include them, and restoring adds them to the ones already on your phone.
- A new tab opens on a start page with your bookmarks, the sites you visit most and recent pages.
- Long-press a video on a page to download it or its stream.
- Pull down on a page to reload it.
- Clear this site's data, in the page menu, signs you out of one site and leaves the others alone.
- Private browsing, in Settings → Browser. Maglev keeps no history and doesn't reopen your tabs. When you leave the browser, it clears the cookies and cached pages of the sites you visited. Site storage and third-party cookies can stay.
- Dark pages, in Settings → Browser, darkens sites that only have a light look while your phone is in dark mode.
- Select a link in any app and choose Download with Maglev from the text menu. You may find it under ⋮.
- Tapping a copied web link opens the same one-tap download sheet as sharing it.
- When Transfers is empty, it shows how to send a link from another app with Share.
- Export debug log, in Settings → About, saves a log you can attach to a bug report. Links, cookies, passwords and tracker keys are removed first.

## What's changed
- Change folder on the add screens now changes the folder for that download only. Your default folder stays the same.
- Torrent network options such as the port, DHT and the blocklist are under Settings → Network → Advanced. Changes apply as soon as you restart the downloader from the banner.
- The blocklist row says whether the list is on, off or can't be read.
- Downloads from the browser send the page's cookies, Referer and Origin on every redirect and stream request, so more sites accept them.
- Speeds show 3 digits, so the numbers on a card stay put.
- In Search, the result count comes first, with one short line about the sources under it.
- Starting the app is faster, and the screen no longer flashes grey first.
- The app is smaller.

## What's fixed
- Opening the same page twice from History now opens it again.
- A site that refuses a link now says "The site refused this link" instead of asking you to sign in.
- Link downloads continue after you switch between Wi-Fi and mobile data.
- When a server limits how many parts it accepts, the download keeps its progress and goes on with fewer parts.
- A link download with no network says No internet connection instead of Waiting for the server.
- Not enough space on the add screens shows how much you need and how much is held for other downloads.
- Feeds: Skip episodes I already have no longer skips the same episode number of another show. A show named only by a year, like 1923, keeps its name.
- A shared web page opens in the Browser tab instead of opening a second copy of the app's tabs.
- If restarting the downloader fails after a network change, Maglev tries again.
- Swipe actions on Transfers rows no longer show at the edges while you aren't swiping.
