## What's new
- Long transfer names can be read in full. A transfer's page shows its whole name under the top buttons: up to 3 lines, then Show more. Select one transfer and its full name shows above Pause, Resume and Delete.
- Settings → Appearance → Transfer name lines: choose 1, 2 or 3 lines on each card in Transfers, or Full name.
- Share a link to a file Maglev doesn't recognise by its name, such as a .bin or .csv file, and Maglev asks the server first. If it's a file, you get the download with its name and size instead of the web page card.

## What's changed
- Maglev can now offer fix releases such as 1.1.1 in its updater, not only new versions such as 1.2.
- "Done in" on a finished video download now includes the time spent joining the video and sound.

## What's fixed
- Opening Maglev from its icon no longer brings back the Add screen of a link you shared earlier and already added or closed.
- The What's New card no longer opens over a link you just shared.
- The start screen shows the Maglev train on Android 12 and later instead of a blank screen.
- "This waits for Wi-Fi." on Add a link and Add torrent now appears and disappears as Wi-Fi drops and comes back while the screen is open.
- Choosing Custom for a speed limit opens the field with the keyboard up.
- At large text sizes, menu labels, filter counts and torrent stats are no longer cut off.
