# Site build

The site in `site/` is plain HTML and CSS. The HTML is generated by `build-site.mjs` and committed; GitHub Pages serves it as is (`.github/workflows/pages.yml`).

```bash
node site/build/build-site.mjs                    # regenerate site/
node site/build/verify.mjs                        # static checks
node site/build/verify.mjs --shots <dir> --prefix v4   # also render index, compare and 404 at 390x844 and 1440x900
```

Node 22, no dependencies. `--shots` finds `playwright-core` the way `store/render.js` does.

## Where things come from

| Output | Source |
|---|---|
| Words: FAQ, feature text and specs, How it works | `content.json` (links as `[text](url)`) |
| Phone screens beside each feature | `store/images/canon/screens/*.png` (1080x2400), encoded once to `assets/screens/<id>-540` and `-1080` as `.webp` and `.avif` (Pillow). Re-encode them if the canon screens change. |
| Comparison teaser on the home page, and `compare/index.html` | `compare.json` (apps, rows, sources, page prose and FAQ). A missing value, or "Not listed", shows as No, except in the `min-android` row. |
| Version, "updated" date | `app.json` `expo.version`; the build date, or `SITE_DATE=YYYY-MM-DD` |
| Base URL for canonical, Open Graph, sitemap, JSON-LD and the 404 page | `SITE_URL` in `build-site.mjs` |
| Signing fingerprint | `FINGERPRINT` in `build-site.mjs` |
| Icons | `components/icons.generated.ts` (Pixelarticons), inlined as SVG |
| JSON-LD: `WebSite`, `WebPage`, `Person`, `SoftwareApplication` and `FAQPage` on the home page; `WebPage`, `BreadcrumbList` and `FAQPage` on compare/ | Generated from the above. Each `FAQPage` text is that page's visible FAQ with links stripped. |

Hand-written files: `assets/site.css`, `assets/site.js`, the fonts in `assets/fonts/` (Inter 400 and 700, and Silkscreen, subset to woff2 with `pyftsubset`), the icons, and `assets/og.png`. `og.png` is a 1200x630 render of the layout in `store/frames/feature.html`. 

## Rules

- Change words in `content.json`, then rebuild. Don't edit `index.html`, `compare/index.html`, `404.html`, `llms.txt`, `sitemap.xml` or `robots.txt` by hand.
- Every claim must be backed by the README or `docs/NATIVE_CONTRACT.md`. Cells about other apps come only from their own pages (`compare.json` lists the sources). Anything a page doesn't list counts as No.
- `index.html` and `compare/index.html` use relative paths, so the same files work at `kaos599.github.io/Maglev/` and at `SITE_URL`. `404.html` is served at any depth, so it uses absolute `SITE_URL` paths.
- Run `verify.mjs` before committing. CI runs its static checks on every deploy.
