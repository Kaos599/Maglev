Maglev as an alternative to ADM

Maglev and ADM both download ordinary web links and torrents, with a browser and a battery cut-off. ADM's Play listing says it contains ads and in-app purchases. Maglev has no ads, and its code is open under GPL-3.0.

Checked 13 November 2026 against Advanced Download Manager (ADM)'s own pages and store listing. Anything those pages don't list counts as No.

Where each answer comes from

  • Maglev Open source: github.com. Torrents, ordinary links and a built-in browser that saves streams, in one free, open source Android app with no ads.
  • Advanced Download Manager (ADM) Closed source: play.google.com. A download manager for Android with a browser, link interception and torrent support. Its Play listing says it contains ads.

What is the same

Both apps download ordinary web links with pause and resume, run torrents, and have a browser. Both keep downloads going in the background with a notification, and both can pause when the battery is low.

Both can pick the files inside a torrent and schedule downloads.

What Maglev adds

Maglev has no ads and no in-app purchases. ADM's Play listing says it contains both. Maglev's browser blocks ads and trackers before they load. ADM's page describes a browser but does not mention ad blocking.

Maglev lists the videos and files a page plays, so you can pick one to save. ADM's page says it has an advanced media downloader, but it does not say how that downloader finds files.

Maglev saves HLS and DASH streams as one file after you pick the quality and audio language. ADM's page does not list either.

One Maglev search box covers more than 40 public torrent sources and merges duplicates. ADM's page does not list a torrent search. Maglev also opens a finished download's folder, which ADM's page does not list. ADM's page lists opening the completed download.

Maglev finds subtitles for videos you have downloaded, from 21 free sources, and saves one next to the video. ADM's page does not list subtitles.

Maglev's browser blocks known crypto-mining scripts and opens pages over HTTPS when the site supports it. ADM's page does not list either.

When ADM is the better choice

Pick ADM if you want an app from Google Play. It installs and updates through the store, and Maglev is installed from GitHub Releases or with Obtainium.

ADM's page lists a home-screen widget. Maglev's README lists a Quick Settings tile.

How to switch

Download the APK for your phone from the Maglev releases page, or add Maglev to Obtainium so updates arrive on their own.

Paste a link into Maglev, or share it to Maglev from any app. Torrents can be opened from a .torrent file or a magnet link in the same way.

Finished files land in Download/Maglev. From a finished item you can tap Open, Share or Open folder.

Questions about switching

Does Maglev have ads, unlike ADM?

No. ADM's Play listing says it contains ads. Maglev has no ads, and its browser blocks ads and trackers on the pages you open.

Is ADM free, and is Maglev free?

Maglev is free software with no ads and nothing to buy. ADM's Play listing says it is free with ads and that a Pro version exists.

Can Maglev save videos from a web page like ADM?

Yes, for the videos and files a page plays or links to. Maglev saves HLS and DASH streams as one file. It cannot save DRM-protected video or live streams.

Is Maglev on Google Play?

Not yet. Install it from GitHub Releases or with Obtainium.
